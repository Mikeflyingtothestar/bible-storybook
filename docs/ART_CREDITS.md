# Art credits

The pictures in the “Art through the ages” section are self-hosted WebP copies. Each original file on Wikimedia Commons reported the license short name **Public domain** when it was checked on 23 November 2026. The copies here are resized and compressed for the web. They are not a substitute for the Commons file page, which remains the source of the license.
